What made it a fair fight

Identical families

Both ran the same 3,946 families (5,446 minus those with <4 species — the filter both tools apply).

Same model

UndatedDTL, global rates, uniform origination, fixed DPANN tree (species-tree-search SKIP).

Same missing-data term

gpurec fm-mode e-only ↔ AleRax --fraction-missing-file, both filtered to the 60 tree species.

Same optimizer family

L-BFGS on both sides, run to each tool's own convergence.

Pinned hardware

gpurec on one A100-80GB (driver-verified); never the mixed/older GPU partition.

Identical CCP inputs

Both consume the same ALE conditional-clade files — no re-derivation between tools.
